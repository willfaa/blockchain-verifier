1. PRASYARAT WAJIB DOCKER DESKTOP (Mencegah Broken Pipe & Unexpected EOF)
-----------------------------------------------------------------------------
Sebelum menjalankan network di WSL, pastikan 2 setelan ini aktif di Docker Desktop Windows:

A. Matikan Containerd Image Store:
   - Buka Docker Desktop -> Settings (roda gigi) -> General (atau Features in development)
   - Hilangkan centang (UNCHECK): "Use containerd for pulling and storing images"
   - Klik "Apply & restart"

B. Atur Min API Version (Settings -> Docker Engine):
   Tambahkan baris "min-api-version": "1.24" pada JSON:
   {
     "builder": {
       "gc": {
         "defaultKeepStorage": "20GB",
         "enabled": true
       }
     },
     "experimental": false,
     "min-api-version": "1.24"
   }
   - Klik "Apply & restart"

6. VALIDASI & QUERY LEDGER VIA PEER CLI (WSL)
-----------------------------------------------------------------------------
A. Inisialisasi Environment Peer:
   export PATH=~/fabric-samples/bin:$PATH
   export FABRIC_CFG_PATH=~/fabric-samples/config/
   export CORE_PEER_TLS_ENABLED=true
   export CORE_PEER_LOCALMSPID="Org1MSP"
   export CORE_PEER_TLS_ROOTCERT_FILE=~/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/peers/peer0.org1.example.com/tls/ca.crt
   export CORE_PEER_MSPCONFIGPATH=~/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp
   export CORE_PEER_ADDRESS=localhost:7051

check status :
peer lifecycle chaincode queryinstalled
peer lifecycle chaincode querycommitted -C chainnesa -n basic



B. Query Semua Data Sertifikat di Ledger:
   peer chaincode query -C chainnesa -n basic -c '{"function":"GetAllCertificates","Args":[]}' | jq .

C. Query Spesifik Berdasarkan ID Sertifikat:
   peer chaincode query -C chainnesa -n basic -c '{"function":"ReadCertificate","Args":["CERT-2026-6776"]}' | jq .

7. SAFE SHUTDOWN VS RESET TOTAL (PERLINDUNGAN DATA)
-----------------------------------------------------------------------------

A. SAFE SHUTDOWN (Data Ledger AMAN - RAM & CPU Bebas):
   Gunakan cara ini ketika selesai bekerja / ingin mematikan komputer tanpa menghapus ledger.
   
   # Mematikan container tanpa hapus volume data:
   docker stop $(docker ps -q)

   # Menyalakan kembali besok:
   docker start ca_orderer ca_org1 ca_org2 orderer.example.com peer0.org1.example.com peer0.org2.example.com

B. RESET TOTAL / FRESH TESTING (Data Ledger DIHAPUS TOTAL):
   Hanya gunakan ini jika ingin mengosongkan riwayat dari nol.
   
   cd ~/fabric-samples/test-network
   ./network.sh down
   docker volume prune -f
   ./network.sh up createChannel -c chainnesa -ca
   # Jalankan kembali langkah 4 & 5

C. DISASTER RECOVERY (Sinkronkan Ulang Antrean DB ke Fabric Baru):
   Jika network baru saja di-reset dan ingin memasukkan kembali data pending dari DB:
   cd C:\Users\willfaa\Documents\VSCode-Project\blockchain-verifier\backend
   npm run sync:fabric -- --force

8. MITIGASI ERROR UMUM
-----------------------------------------------------------------------------

A. Error "Config File core Not Found":
   Pastikan environment variable sudah di-load:
   export FABRIC_CFG_PATH=~/fabric-samples/config/

B. Error "Cannot connect to the Docker daemon":
   Docker Desktop Windows belum running atau WSL terputus:
   1. Pastikan Docker Desktop di Windows statusnya "Engine running".
   2. Jika macet, restart WSL di PowerShell: wsl --shutdown

C. Port Terkunci / Conflict:
   - Cek port: netstat -ano | findstr :7051
   - Matikan PID: taskkill /PID <PID_PROSES> /F
