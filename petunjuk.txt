=============================================================================
           PETUNJUK PENYELARASAN & MENJALANKAN HYPERLEDGER FABRIC
=============================================================================

-----------------------------------------------------------------------------
1. PERSIAPAN / CLEANUP MANDATORI (Penting jika ada konflik port/sertifikat)
-----------------------------------------------------------------------------
A. Matikan Service Docker bawaan WSL (agar tidak konflik port dengan Docker Desktop):
   sudo service docker stop
   sudo systemctl stop docker
   sudo systemctl stop docker.socket

B. Hapus container & volume usang / legacy:
   docker rm -f ca_orderer ca_org1 ca_org2 peer0.org1.example.com peer0.org2.example.com orderer.example.com
   docker volume prune -f

C. Bersihkan sisa sertifikat lama di folder network:
   cd ~/fabric-samples/test-network
   ./network.sh down
   # Hapus manual jika masih tersisa:
   rm -rf organizations/peerOrganizations
   rm -rf organizations/ordererOrganizations
   rm -rf organizations/fabric-ca/org1/{msp,*.pem,*.db,Issuer*}
   rm -rf organizations/fabric-ca/org2/{msp,*.pem,*.db,Issuer*}
   rm -rf organizations/fabric-ca/ordererOrg/{msp,*.pem,*.db,Issuer*}

-----------------------------------------------------------------------------
2. BOOTSTRAP NETWORK & BUAT CHANNEL (Jalankan di WSL)
-----------------------------------------------------------------------------
A. Nyalakan network dan CA, serta buat channel:
   cd ~/fabric-samples/test-network
   ./network.sh up createChannel -c mychannel -ca

-----------------------------------------------------------------------------
3. DEPLOY CHAINCODE / SMART CONTRACT (Jalankan di WSL)
-----------------------------------------------------------------------------
A. Jalankan perintah deployCC (Pastikan path Go ditambahkan ke PATH):
   export PATH=/usr/local/go/bin:$PATH
   ./network.sh deployCC \
     -ccn basic \
     -ccp /mnt/c/Users/willfaa/Documents/VSCode-Project/blockchain-verifier/chaincode-go \
     -ccl go \
     -ccep "OR('Org1MSP.peer','Org2MSP.peer')" \
     -cci InitLedger

-----------------------------------------------------------------------------
4. PENGUJIAN / VALIDASI VIA PEER CLI (Jalankan di WSL)
-----------------------------------------------------------------------------
A. Set Environment variables terlebih dahulu (Gunakan absolute path agar bisa dijalankan dari folder mana saja di WSL):
   export PATH=~/fabric-samples/bin:$PATH
   export FABRIC_CFG_PATH=~/fabric-samples/config/
   export CORE_PEER_TLS_ENABLED=true
   export CORE_PEER_LOCALMSPID="Org1MSP"
   export CORE_PEER_TLS_ROOTCERT_FILE=~/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/peers/peer0.org1.example.com/tls/ca.crt
   export CORE_PEER_MSPCONFIGPATH=~/fabric-samples/test-network/organizations/peerOrganizations/org1.example.com/users/Admin@org1.example.com/msp
   export CORE_PEER_ADDRESS=localhost:7051

B. Check list channel & chaincode terinstall:
   peer channel list
   peer lifecycle chaincode queryinstalled

C. Query data awal (pastikan CORE_PEER di atas sudah di-export):
   peer chaincode query -C mychannel -n basic -c '{"function":"GetAllCertificates","Args":[]}'

-----------------------------------------------------------------------------
5. KONFIGURASI BACKEND & WALLET SINKRONISASI
-----------------------------------------------------------------------------
A. Jalankan auto-config script di WSL untuk menyalin sertifikat terbaru & generate profile:
   cd /mnt/c/Users/willfaa/Documents/VSCode-Project/blockchain-verifier/backend
   ./auto-config.sh

B. Sinkronisasi Wallet (Jalankan di Windows CMD/PowerShell agar bisa membaca PostgreSQL di localhost:5433):
   cd C:\Users\willfaa\Documents\VSCode-Project\blockchain-verifier\backend
   npx ts-node src/fabric/scripts/syncWallet.ts

-----------------------------------------------------------------------------
6. PENANGANAN MASALAH PORT BLOCKED (Windows CMD Admin)
-----------------------------------------------------------------------------
Jika port backend (8081 / 4000) terpakai atau crash:
   netstat -ano | findstr :8081
   taskkill /PID <PID_BARIS_PALING_KANAN> /F
